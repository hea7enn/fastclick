# 📱 微信小程序答题系统 - 使用指南

## 🚀 快速开始

### 第一步：安装微信开发者工具

1. 访问[微信开发者工具下载页](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 根据你的操作系统下载对应版本
3. 安装并启动微信开发者工具

### 第二步：导入项目

1. 打开微信开发者工具
2. 点击「+」号或「导入项目」
3. 填写项目信息：
   - **项目目录**：选择本项目的 `miniprogram` 文件夹
   - **AppID**：选择「使用测试号」（或填写已注册的小程序 AppID）
   - **项目名称**：任意填写，如「答题系统」
4. 点击「导入」

### 第三步：运行项目

项目导入后会自动编译和运行，你应该能在模拟器中看到小程序界面。

## 🎮 功能演示

### 1️⃣ 首页

首页展示了学习数据总览和快捷入口：
- 点击「极速开考」立即开始答题
- 点击「浏览题库」进入题库页面
- 查看累计答题数据（题库数量、考试次数、正确率等）

### 2️⃣ 题库

在题库页面，你可以：
- 按**分类**筛选（基础知识、操作实践、高阶挑战）
- 按**难度**筛选（简单、中等、困难）
- 按**题型**筛选（单选题、多选题、判断题、填空题）
- 点击题目预览内容
- 点击「开始练习」开始答题

### 3️⃣ 答题

答题界面功能：
- **实时计时**：显示已用时间
- **进度显示**：显示当前进度（如 3/10）
- **题目导航**：上一题/下一题按钮
- **自动保存**：答案实时保存到本地
- **提交确认**：未作答题目会弹出确认提示

**答题操作：**
- **单选题**：点击选项即可选择
- **多选题**：点击选项可多选，再次点击取消选择
- **判断题**：选择「正确」或「错误」
- **填空题**：在文本框中输入答案

### 4️⃣ 成绩展示

提交答卷后会看到：
- **得分**：你的分数和总分
- **正确率**：答对题目的百分比
- **用时**：完成答题所用时间
- **操作按钮**：
  - 「再来一次」：使用相同题目重新答题
  - 「查看解析」：展开/收起答案解析
  - 「返回首页」：返回首页

### 5️⃣ 个人中心

个人中心包含三个标签页：

**概览**
- 查看学习统计数据
- 快速开始新的测验

**历史成绩**
- 查看所有答题记录
- 显示得分、正确率、用时等信息

**错题本**
- 查看所有答错的题目
- 显示你的答案和正确答案
- 点击「标记已掌握」移除错题

## 📚 自定义题库

### 方式一：修改默认题库

编辑 `utils/questionData.js` 文件，在 `defaultQuestions` 数组中添加题目：

```javascript
{
  id: 'single-010',           // 唯一标识
  type: 'single',             // 题型：single/multiple/judge/fill
  category: '基础知识',        // 分类
  question: '你的题目内容',    // 题目内容
  options: [                  // 选项（单选、多选、判断题）
    { key: 'A', value: '选项A' },
    { key: 'B', value: '选项B' },
    { key: 'C', value: '选项C' },
    { key: 'D', value: '选项D' }
  ],
  answer: 'A',                // 正确答案
  analysis: '答案解析说明',   // 解析
  difficulty: 'medium',       // 难度：easy/medium/hard
  score: 2                    // 分值
}
```

**题型说明：**

- **单选题** (`type: 'single'`)
  - `answer` 为单个字符串，如 `'A'`
  
- **多选题** (`type: 'multiple'`)
  - `answer` 为数组，如 `['A', 'C']`
  
- **判断题** (`type: 'judge'`)
  - `options` 固定为：
    ```javascript
    [
      { key: 'A', value: '正确' },
      { key: 'B', value: '错误' }
    ]
    ```
  - `answer` 为 `'A'` 或 `'B'`

- **填空题** (`type: 'fill'`)
  - `options` 为空数组 `[]`
  - `answer` 为字符串，如 `'npm'`

### 方式二：重置题库数据

在微信开发者工具的「调试器」-「Storage」中：
1. 找到 `questionBank` 存储项
2. 删除该项
3. 重新启动小程序，系统会重新初始化默认题库

## 🔧 清除数据

### 清除所有数据

在微信开发者工具中：
1. 点击菜单「工具」-「清除缓存」-「清除全部缓存」
2. 或在「调试器」-「Storage」中手动删除各项数据

### 仅清除特定数据

**清除答题记录：**
```javascript
wx.removeStorageSync('examRecords')
```

**清除错题本：**
```javascript
wx.removeStorageSync('wrongQuestions')
```

## 🎨 自定义主题

### 修改主色调

编辑 `app.wxss` 和 `styles/common.wxss`，替换主色值：

```css
/* 当前主色：#4F46E5 (Indigo) */
/* 可替换为其他颜色，如： */
/* #3B82F6 (蓝色) */
/* #10B981 (绿色) */
/* #F59E0B (橙色) */
```

### 修改导航栏

编辑 `app.json` 的 `window` 配置：

```json
{
  "navigationBarBackgroundColor": "#4F46E5",
  "navigationBarTitleText": "你的标题",
  "navigationBarTextStyle": "white"
}
```

## 🐛 常见问题

### Q: 小程序打不开或报错？
**A:** 检查以下几点：
- 确保微信开发者工具版本是最新的
- 检查 `app.json` 配置是否正确
- 查看控制台是否有错误信息

### Q: 题库数据没有显示？
**A:** 
- 打开调试器 - Storage，查看 `questionBank` 是否有数据
- 如果没有，删除该项并重启小程序

### Q: 答题记录或错题本不见了？
**A:** 
- 数据存储在本地，清除缓存会丢失
- 确认是否在调试器中手动删除了数据

### Q: 如何实现云端同步？
**A:** 
可以接入微信云开发：
1. 在 `project.config.json` 中配置云开发
2. 将本地存储改为云数据库操作
3. 实现多端数据同步
