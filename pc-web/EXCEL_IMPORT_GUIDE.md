# Excel 题库导入功能使用指南

## 功能概述

本系统支持通过 Excel 文件批量导入题库，支持四种题型：单选题、多选题、判断题、填空题。

## Excel 模板格式

### 表格列说明

| 列名 | 说明 | 必填 | 示例 |
|------|------|------|------|
| 题型 | 题目类型 | ✅ | 单选、多选、判断、填空 |
| 分类 | 题目分类/科目 | ❌ | 数学、英语、物理等 |
| 题目内容 | 题目描述 | ✅ | 1+1等于几？ |
| 选项A | 第一个选项 | 选择题必填 | 1 |
| 选项B | 第二个选项 | 选择题必填 | 2 |
| 选项C | 第三个选项 | 选择题可选 | 3 |
| 选项D | 第四个选项 | 选择题可选 | 4 |
| 正确答案 | 正确答案 | ✅ | B 或 A,C 或 正确 或 秦朝 |
| 解析 | 答案解析 | ❌ | 基础加法运算 |
| 难度 | 难度等级 | ❌ | 简单、中等、困难 |
| 分值 | 题目分值 | ❌ | 5 |

### 题型说明

#### 1. 单选题
- **题型填写**：单选、单选题
- **选项要求**：至少需要2个选项（选项A、选项B）
- **答案格式**：单个选项字母，如：`A`、`B`、`C`、`D`

#### 2. 多选题
- **题型填写**：多选、多选题
- **选项要求**：至少需要2个选项
- **答案格式**：多个选项字母用逗号分隔，如：`A,B,C` 或 `A，C`（支持中英文逗号）

#### 3. 判断题
- **题型填写**：判断、判断题
- **选项要求**：自动生成"正确"和"错误"选项
- **答案格式**：
  - 表示正确：`正确`、`对`、`TRUE`、`T`、`A`
  - 表示错误：`错误`、`错`、`FALSE`、`F`、`B`

#### 4. 填空题
- **题型填写**：填空、填空题
- **选项要求**：无需填写选项
- **答案格式**：直接填写答案文本，如：`秦朝`

## 使用步骤

### 1. 下载模板
1. 进入"题库管理"页面
2. 点击"下载模板"按钮
3. 获得 `题库导入模板.xlsx` 文件

### 2. 填写题目
在模板中按照格式要求填写题目数据，可以参考模板中的示例数据。

### 3. 导入题库
1. 点击上传区域或拖拽Excel文件到上传区域
2. 系统会自动解析和验证数据
3. 如果有错误会显示错误列表，请根据提示修改Excel文件后重新导入
4. 导入成功后，题目会自动添加到题库中

### 4. 管理题目
- **查看**：在题目列表中查看所有题目
- **筛选**：使用题型、分类、难度筛选器快速查找题目
- **搜索**：在搜索框中输入关键词搜索题目内容
- **编辑**：点击"编辑"按钮修改题目信息
- **删除**：点击"删除"按钮删除题目
- **导出**：点击"导出Excel"按钮将题库导出为Excel文件

## 数据验证规则

系统会对导入的数据进行以下验证：

1. **必填字段验证**
   - 题型不能为空
   - 题目内容不能为空
   - 正确答案不能为空

2. **题型验证**
   - 题型必须是：单选/多选/判断/填空

3. **选项验证**
   - 选择题至少需要2个选项
   - 选项内容不能为空

4. **答案验证**
   - 单选题：答案必须是选项中的一个
   - 多选题：答案必须都在选项中
   - 判断题：答案必须符合格式要求
   - 填空题：答案不能为空

5. **数值验证**
   - 分值必须是大于0的数字

## 常见问题

### Q1: 导入失败，提示"题型不能为空"
**A**: 请检查Excel中的"题型"列是否有空白行，确保每道题都填写了题型。

### Q2: 选择题导入失败，提示"选择题至少需要2个选项"
**A**: 选择题的选项A和选项B是必填的，请确保至少填写了这两个选项。

### Q3: 多选题答案格式不正确
**A**: 多选题答案需要用逗号分隔，如：`A,B,C`，支持中英文逗号。

### Q4: 判断题答案无法识别
**A**: 判断题答案支持多种格式：
- 正确：正确、对、TRUE、T、A
- 错误：错误、错、FALSE、F、B

### Q5: 导入后找不到题目
**A**: 
- 检查是否导入成功（页面会显示成功提示）
- 使用搜索和筛选功能查找题目
- 查看浏览器控制台是否有错误信息

### Q6: 如何批量修改已导入的题目
**A**: 
1. 使用"导出Excel"功能导出当前题库
2. 在Excel中修改数据
3. 删除原有题目或清空题库
4. 重新导入修改后的Excel文件
